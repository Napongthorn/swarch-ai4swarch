# สะท้อนคิดรายบุคคล (≤ 150 คำ)

**ชื่อ / รหัสนิสิต:** ณพงษ์ธร เจริญลาภ / 6631313321
**บทบาทของฉันในคณะกรรมการ:** ไม่ได้เข้าร่วม

หลังจากทำส่วน A และส่วน B แล้ว นิสิตจะไว้วางใจให้ AI ทำงานส่วนใดของสถาปนิก และจะเก็บงานส่วนใดไว้ให้มนุษย์ ยกตัวอย่างที่เป็นรูปธรรมหนึ่งตัวอย่างจากการประชุมคณะกรรมการ

ผมไม่ได้เข้าร่วมประชุม จึงขอยกตัวอย่างจากส่วน A แทน

ผมไว้ใจให้ AI ช่วยงานที่ต้องอ่านเยอะ เช่น หา dependency จากไฟล์ config ร่าง ADR ให้ครบหัวข้อ และรีวิวหาจุดอ่อน ซึ่ง AI ทำได้เร็วและจับจุดที่ผมมองข้ามได้ เช่น รูของ outbox ที่ผมเพิ่มเข้าไปเอง

แต่งานที่ต้องเก็บไว้ให้คนคือการตรวจและตัดสินใจ ตัวอย่างคือ AI คำนวณอัตรา MailFast ล้มผิด เพราะใช้ 200 orders/s แทน 50 ครั้งต่อวินาที ตัวเลขดูน่าเชื่อถือแต่ผิด ถ้าไม่เช็กเองก็จะหลุดไปใน ADR ส่วนร่าง ADR แรกก็ยอมให้ event หาย ซึ่งขัดกับ requirement ผมต้องเป็นคนเลือกแก้เองด้วย outbox
